# Contributing to HeMan Vibes

Thank you for your interest in contributing to **HeMan Vibes**! We welcome bug reports, feature suggestions, and code contributions from everyone.

---

## 🛠️ Development Setup

1. Fork and clone the repository:
   ```bash
   git clone https://github.com/hemansubedi10/HeManVibes.git
   cd HeManVibes
   ```
2. Verify you have **Java JDK 21+** installed:
   ```bash
   java -version
   ```
3. Open the project in **Android Studio** (or IntelliJ IDEA / VS Code with KMP extension).

---

## 🧪 Running Locally

* **Desktop (Windows/Mac/Linux):**
  ```bash
  ./gradlew :desktopApp:run
  ```
* **Android:**
  ```bash
  ./gradlew :androidApp:installDebug
  ```

---

## 🚀 Submitting a Pull Request

1. Create a feature branch:
   ```bash
   git checkout -b feature/your-feature-name
   ```
2. Make your improvements and verify that the app builds without errors.
3. Commit with clear, descriptive messages:
   ```bash
   git commit -m "feat: add 10-band equalizer support"
   ```
4. Push to your fork and submit a Pull Request to `main`.
