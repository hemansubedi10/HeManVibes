# 🗺️ HeMan Vibes Roadmap

Here is the strategic development roadmap for upcoming releases of **HeMan Vibes**.

---

### 🟢 Version 1.0.0 (Current Release)
- [x] Cross-platform support for Android, Windows, macOS, iOS, and Linux.
- [x] Real-time YouTube Music InnerTube search & catalog extraction.
- [x] Millisecond-accurate timestamped synced lyrics via LRCLIB.
- [x] Material 3 Expressive animated Wavy Seek Bar.
- [x] Apple Music-style fluid ambient mesh backdrop.
- [x] Live search suggestions with instant debounced completion.
- [x] Up Next queue modal & Sleep Timer.
- [x] Pure Obsidian AMOLED dark theme mode.

---

### 🟡 Version 1.1.0 (Q1 2027)
- [ ] **Android Auto Support:** Full car infotainment dashboard integration with playlist voice search.
- [ ] **Graphic Equalizer & Bass Boost:** 10-band audio equalizer with preset sound profiles (Rock, Bass Boost, Vocal, Acoustic).
- [ ] **Spotify & Apple Music Import:** Paste any public Spotify or Apple Music playlist link to automatically resolve and play tracks on HeMan Vibes.
- [ ] **Listen Together (SyncPlay):** Real-time synchronized music room listening with friends over WebSockets.

---

### 🔵 Version 1.2.0 (Q2 2027)
- [ ] **Discord Rich Presence (RPC):** Show what you're listening to on Discord with album artwork and playback progress.
- [ ] **Last.fm Scrobbling:** Automatic background scrobble support.
- [ ] **SponsorBlock Integration:** Automatically skip non-music intros, music video dialogs, and channel promos.
- [ ] **Offline Multi-Track Downloader:** Background multi-threaded downloader with embedded ID3 tags and album covers.
